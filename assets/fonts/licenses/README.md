# Bundled Font Licenses

Overlay Studio bundles the following Google Fonts so overlays keep their chosen
typography without an internet connection and PNG exports can render the exact
same glyphs as OBS:

- Anton
- Archivo Black
- Fredoka
- Montserrat
- Nunito
- Poppins

Each family is distributed under the SIL Open Font License 1.1. Its family-specific
license text is stored beside this file as `<family>-OFL.txt`.

The WOFF2 files and `overlay-fonts.css` were retrieved from the official Google
Fonts CSS service on 2026-08-15. Source metadata and upstream font files are
maintained in the [Google Fonts repository](https://github.com/google/fonts).

Minecraft Clock Line, Minecraft Countdown Line, Minecraft Stopwatch Line, Block Beats,
and Minecraft Spotify bundle `Minecraftia-Regular.ttf` by Andrew Tyler, retrieved from
[DaFont](https://www.dafont.com/minecraftia.font) on 2026-08-29. The project owner
confirmed that they purchased the separate commercial/app license required by the
author. The purchase receipt is retained privately by the project owner outside this
repository. The archive's author notice is stored as `minecraftia-README.txt`; the
purchaser's nontransferable license and receipt are not redistributed here.
